# gales-hero-animation

241 JPEG frames (1280x720, RGB) of the Gales Ilusionista hero video, for use as a scroll-driven or frame-sequence hero animation.

- Frames: `frames/frame-001.jpg` ... `frames/frame-241.jpg` (zero-padded, sequential, 1-based)
- Total size: about 5.3 MiB (5,556,879 bytes)
- Base URL: `https://raw.githubusercontent.com/josiscripts/gales-hero-animation/main/frames/`

Frame URL pattern: `https://raw.githubusercontent.com/josiscripts/gales-hero-animation/main/frames/frame-{NNN}.jpg` where `NNN` is the 3-digit frame number 001 to 241.

Frames were taken unchanged from the source archive (already compressed; re-encoding at quality 80 increased the size, so originals are kept).
