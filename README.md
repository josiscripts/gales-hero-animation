# gales-hero-animation

211 JPEG frames (3840x2160, RGB) of the Gales Ilusionista hero video, for use as a scroll-driven or frame-sequence hero animation.

- Frames: `frames/frame-001.jpg` ... `frames/frame-211.jpg` (zero-padded, sequential, 1-based)
- Total size: about 23.9 MiB (25,113,878 bytes)
- Base URL: `https://raw.githubusercontent.com/josiscripts/gales-hero-animation/main/frames/`

Frame URL pattern: `https://raw.githubusercontent.com/josiscripts/gales-hero-animation/main/frames/frame-{NNN}.jpg` where `NNN` is the 3-digit frame number 001 to 211.

Frames are taken unchanged from the source archive.
